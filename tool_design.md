# Описание пяти Tool для LLM-агента

У каждого инструмента есть понятный «договор»: имя, назначение, вход, выход, ошибки и ограничения.

## 1. Калькулятор (`calculator`)

- **Назначение:** точные вычисления. Используется, когда в вопросе есть расчёт (например, «17% от 125 000»).
- **Вход:** числа и действие (например, 125000, 17, «процент»).
- **Выход:** результат расчёта (21 250).
- **Ошибки:** неверные данные (текст вместо числа), деление на ноль — сообщить, что посчитать не получилось.
- **Ограничения:** только считает, никуда не имеет доступа. Не вызывается, если расчёт не нужен.

## 2. Поиск по файлам (`file_search`)

- **Назначение:** найти нужную информацию в документах.
- **Вход:** название документа и что искать (например, «требования к системе»).
- **Выход:** найденный фрагмент текста.
- **Ошибки:** файл не найден, раздел не найден — сообщить об этом пользователю.
- **Ограничения:** только чтение, только разрешённая папка. Не может удалять или менять файлы.

## 3. Статус обращения (`get_ticket_status`)

- **Назначение:** узнать статус обращения во внутренней системе.
- **Вход:** номер обращения (например, 5412).
- **Выход:** статус обращения (например, «в работе»).
- **Ошибки:** обращение не найдено, система недоступна — честно сообщить, не придумывать статус.
- **Ограничения:** доступ только на чтение статусов, без доступа ко всей базе данных.

## 4. Конвертер единиц (`unit_converter`)

- **Назначение:** перевести значение из одних единиц в другие (например, 3 ГБ в МБ).
- **Вход:** число, исходная единица, нужная единица.
- **Выход:** число в новой единице (3 ГБ = 3072 МБ).
- **Ошибки:** неизвестная единица или несовместимые единицы (кг в метры) — сообщить об ошибке.
- **Ограничения:** только расчёт, без доступа к данным.

## 5. Планировщик (`calendar_check`)

- **Назначение:** проверить, есть ли свободное время для встречи.
- **Вход:** дата, время, длительность встречи, участники.
- **Выход:** свободно / занято, варианты свободного времени.
- **Ошибки:** календарь недоступен, неверная дата — сообщить и предложить попробовать позже.
- **Ограничения:** только просмотр занятости. Создавать или удалять встречи без подтверждения человека нельзя.
