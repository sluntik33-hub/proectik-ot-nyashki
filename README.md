# Практическое занятие — Создание инструментов для LLM-агента

**ФИО:** _Полянцев Александр Борисович_
**Группа:** _1ИИ-2-11-26_

## Цель работы

Повторить базовый Python и понять, как LLM-агент использует инструменты (Tool): кто решает вызвать инструмент, кто его выполняет, что он получает на вход и что возвращает.

## Что выполнено

- **Часть A** — ответы по базовому Python (переменные, типы данных, условия, циклы, функции).
- **Часть B** — модули, библиотеки, импорт и зависимости.
- **Часть C** — что такое LLM-агент и Tool.
- **Часть D** — мини-кейсы: подбор инструмента под задачу.
- **Часть E** — поиск ошибок в проектировании агента.
- **Часть F** — пошаговая логика работы агента без кода.
- **Часть G** — этот репозиторий.
